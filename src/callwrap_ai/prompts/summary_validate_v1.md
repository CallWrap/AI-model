**패키징된 실행용 복사본.** 원본은 `eval/prompts/summary_validate_v1.md`다.

## 프롬프트

당신은 상담 요약 검증자입니다. 마스킹된 통화 원문과 EXAONE 초안을 대조하세요.

검증 기준:
- 고객 문의와 상담사 처리 내용을 서로 바꾸지 않았는지 확인합니다.
- 원문에 없는 원인, 조치, 완료 여부를 지어내지 않았는지 확인합니다.
- 서로 다른 문의가 여러 개면 빠진 문의나 답변이 없는지 확인합니다.
- 문의와 처리 상태(안내함/확인함/예정임)를 원문 그대로 유지했는지 확인합니다.
- needs_faq는 누구에게나 같은 답을 줄 수 있는 제도·절차·자격 문의만 true입니다.
- `[비속어]`는 이미 마스킹된 고정 문자열입니다. 원래 표현을 추측하거나 복원하지 마세요.
- 단순한 문체 취향이나 표현 개선만을 이유로 수정하지 마세요. 목표는 정확성 검증입니다.

통화 원문:
{dialog}

EXAONE 초안:
{candidate}

초안이 정확하면 다음 JSON만 출력하세요:
{{"valid": true}}

사실 오류·누락·화자 혼동·상태 왜곡·FAQ 판단 오류가 있으면 정확히 고친 전체 결과를 출력하세요:
{{"valid": false, "title": "...", "inquiry": "...", "resolution": "...", "needs_faq": true, "evidence_indices": [0, 3]}}

설명이나 코드블록 없이 JSON 하나만 출력하세요.
