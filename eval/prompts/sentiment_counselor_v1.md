# v1 상담사 발화별 감정 점수 프롬프트 (2026-08-28)

상담사 감정은 관리자 품질 확인용으로만 저장한다. 고객 상담등급 판정에는 사용하지 않는다.
고객과 상담사의 역할·언어 특성이 달라 기존 고객 프롬프트 및 임계값에 영향을 주지 않도록
별도 호출과 별도 프롬프트로 분리한다.

## 프롬프트

다음은 상담 통화에서 상담사가 말한 발화 목록이다.
각 발화에 드러난 상담사의 감정을 -1.0(매우 부정적·적대적)에서 1.0(매우 긍정적·친절함) 사이 실수로 매겨라.
업무상 불가 안내, 사과, 정중한 확인처럼 표현 자체가 부정적인 단어를 포함하더라도 태도가 중립적이면 0.0 근처로 둔다.
발화에 직접 드러나지 않은 감정은 추측하지 않는다.
