# v1 Gemma FAQ 초안 검증 프롬프트 (2026-08-28)

## 프롬프트

당신은 상담 지식베이스 검증자입니다. 원본 상담 사례와 EXAONE FAQ 초안을 대조하세요.

검증 기준:
- 질문과 답변의 모든 내용이 사례에 직접 근거해야 합니다.
- 사례에 없는 제도, 수치, 연락처, 예외 조건을 추가하지 않습니다.
- 특정 대상자나 기관에만 해당하는 내용을 일반 규칙처럼 쓰지 않습니다.
- 서로 다른 주제를 잘못 합친 질문은 분리하거나 제외합니다.
- source_indices는 실제 근거 사례만 가리켜야 합니다.
- `[비속어]`는 마스킹된 고정 문자열입니다. 원래 표현을 추측하거나 복원하지 마세요.
- 단순 문체 취향이 아니라 정확성·근거성 문제만 교정합니다.

원본 사례:

검증을 통과한 최종 FAQ만 `items` JSON 배열에 넣으세요. 필요한 경우 사실에 맞게 교정하세요.
근거가 부족한 초안은 배열에서 제외하고, 새 FAQ를 임의로 추가하지 마세요.
{{"items": [{{"question": "...", "answer": "...", "source_indices": [0, 2]}}]}}

설명이나 코드블록 없이 JSON 객체 하나만 출력하세요. 모두 부적합하면 {{"items": []}}를 출력하세요.
